# North Valley College Website

This project is a static multi-page college website built using only HTML and CSS.

## Pages included

1. Home
2. About
3. Programs
4. Admissions
5. Campus Life
6. Student Support
7. Gallery
8. Contact
9. FAQ

## Navigation

The website uses a consistent top navigation bar on every page. Each page has a visible active state and links to all main sections. Navigation is simple and easy to follow for visitors.

## CSS usage

The styling is centralized in `css/style.css`. It includes:

- color palette and theme design
- responsive layout for mobile and desktop
- reusable card and section styles
- banner and hero sections
- footer and navigation styling
- grid-based page layouts

## Local preview

Open `index.html` in a browser or run a local server from the project folder.

## Deployment note

After pushing this project to GitHub, it can be deployed with GitHub Pages or Netlify as a static website.
